# Amazon DynamoDB 스터디

Amazon DynamoDB 스터디 내용을 기록하는 repo입니다.
두 권의 책을 **병행**해서 읽으며, 개념 → 전략 → 실전 예제 순으로 깊이를 쌓아가는 것을 목표로 합니다.

## 🎯 스터디 방식

- **개념서(DeBrie)** 와 **원서(정의서)** 를 병행하며, 같은 주제를 두 관점에서 교차 학습합니다.
- 매주 읽기와 함께 **설계 실습**을 진행하고, 후반부에는 **실전 예제 → 캡스톤 프로젝트**로 이어집니다.
- 아래 리듬에 맞춰 각 병행 구간의 학습 효과를 극대화합니다.

## 🕒 병행 리듬 요약

| 구간 | 시점 | 내용 |

| **개념 병행** | 4주차 | 단일 테이블(Single Table) 개념이 잡히는 시점에 두 책을 나란히 읽습니다. |
| **전략 병행** | 7~8주차 | 두 책이 **인덱스·샤딩**을 함께 다뤄 병행 효과가 가장 큰 구간입니다. |
| **실전 예제 완성** | 9주차 ~ | 실전 예제를 완성하며 **캡스톤 프로젝트**로 이어갑니다. |
